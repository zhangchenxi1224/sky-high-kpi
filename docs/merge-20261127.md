# test 与微信试玩包合并说明

规则版本：2026.11.5。独立分支：`codex/merge-test-bird-20261127`。

## 来源

- GitHub test：`b3537c41b0b2c6f28ebce21ac37c82d4ccaf3a78`，提供新版收益、概率、镜头和细腻楼体运动。
- GitHub main：`7ae745e`，提供像素 UI、12 套称号、4 种社交属性及海报扩展。
- 用户提供的微信 `sky-high-kpi-playable` 包：恢复小鸟、口粮、喂食、气泡、体测逻辑及 5 张新增图片。该包只有构建文件，相关功能已还原为独立 TypeScript / React 源码。

## 用户确认的冲突选择

| 项目 | 合并结果 |
| --- | --- |
| 每块操作时间 | 6 秒，采用微信版 |
| 课业、科研、竞赛与基础概率 | 采用 test：GPA 0.20/0.23/0.26，科研普通落稳 70%，竞赛 4/6，八类 smoothstep 概率 |
| 体测接入 | 前 3 目标层不出现；第 4 层起固定 4%；保留 test 的诱惑概率，其余七类按比例缩减 |

先确定 test 的诱惑概率（高压翻倍、封顶 10%），再分配体测 4%。其余七类共占 `1 - 诱惑概率 - 0.04`。例如 35 层高压时：诱惑 10%、体测 4%、其他 86%。

## 保留与恢复的功能

- test：细腻/经典摇晃切换、连续搭偏回弹与对齐回稳、第 3～6 层拉远、横屏吊砖间距、固定演示与随机试玩入口、固定 120Hz 自动演示。
- 微信/main：像素标签与弹窗、12 套结算称号、4 种社交属性、1103 彩蛋、海报扩展。
- 小鸟：首页飞行和喂食、气泡开关与自动显隐、结算口粮、回首页入口。存储键保持 `sky-high-kpi-bird-v1`；偏好键保持 `sky-high-kpi-v1`。
- 体测：独立第 13 款精灵，落稳不增加五维 KPI；竞赛+志愿达到 30 不新增扰动，否则后 1～3 投摆速/幅 +15%。
- 离线包：小鸟、体测和原精灵全部内嵌；图片只存一份供界面和 Canvas 共用。

浏览器验收发现气泡偶尔遮住开始按钮，合并版增加了操作区避让；无状态的隐藏气泡也不再参与键盘聚焦。
