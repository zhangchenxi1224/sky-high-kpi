# 抖音近期热梗整理（2026-11）

检索日期：2026-11-26
用途：为《绩点卷上天》补充不遮挡玩法、适合校园语境的轻量弹幕。

## 收录口径

- 优先选近期短视频评论区、二创标题中可直接复用的短句。
- 优先与学习、赶 DDL、熬夜、宿舍、游戏体验相关的表达。
- 不收录涉及真实个人被网暴、地域歧视、健康误导或来源争议的梗。
- 现有诱惑砖已使用 12 格双窗精灵，本次只补充弹幕和文案，不新增砖块类型，避免破坏固定测试序列。

## 已加入弹幕池

| 热梗 | 游戏中的用途 | 处理方式 |
| --- | --- | --- |
| 神之六秒 | 连续完美、极限速度 | 结合本游戏 6 秒 DDL，写成「神之六秒」 |
| 胆子真是肥嘟嘟的 | 完美、极限速度 | 用于玩家冒险卡点或吊车进入高速状态 |
| 贵是贵点，但吃了不烧心 / 不烧心 | 完美、安全落点 | 保留现有的红果诱惑文案，并补「这波不烧心」 |
| 低山臭水遇知音 | 连续完美 | 放在高连击反馈中，作为轻松的伙伴感表达 |
| 那咋了，受着呗 | 擦边落稳、失败 | 用于低空险过和游戏结束的自嘲 |
| 不知道，我的身材很曼妙 | 擦边落稳 | 作为答非所问式过关弹幕 |
| 算了嘛警官 | 擦边落稳、失败 | 用于求系统放过的语气 |
| 慌啥子嘛 | 擦边落稳、极限速度 | 用于低速险些过关和高速吊车两种状态 |
| 地球 Online | 高空、失败 | 把游戏世界和现实生活的“Online”感连起来 |
| 我见识到我自己的厉害了 | 高空 | 作为高层自我鼓励文案 |
| 我将辞职专心研究…… | 失败 | 改编为「我将辞职专心研究这一局」 |

## 保留的旧梗

`夯爆了`、`助我破鼎`、`xx 基础 xx 不基础`、`如何呢又能怎`、`爱你老己`、`画地为牢厉娜` 等仍保留。它们已经渗透到 2025–2026 的持续二创中，不属于一次性的单条热点。

## 未采用

- `来都来了`：与具有争议的社会事件绑定，容易被误读。
- `安卓人 / 苹果人`：带有明显的人群标签和对立性，不适合作为游戏默认弹幕。
- `嘉豪`：梗的传播涉及真实学生被起哄，保留边界。
- 与地域、亲密行为或健康功效相关的表达：可能造成误导，不放进默认文案。
